# RCCI Dahsboard3 (CustomTkinter)

This is a separate modern desktop alternative to `RUN_1/rcci_gui.py`. It imports the original analyzer functions, so it keeps the same workbook inputs, performance-row selection, combustion calculations, report generation, and plots. It adds a dark dashboard layout, confirmation dialog, progress animation, and a background analysis thread so the window stays responsive.

From the RCCI project directory:

```powershell
.\.venv\Scripts\python.exe .\Dahsboard3\rcci_customtkinter.py
```

If using another Python environment, install `Dahsboard3/requirements.txt` first.
